# KUN HONG Portfolio Design Specification

> 最后更新：2026-08-14  
> 适用项目：`portfolio`  
> 线上主域名：`https://kunh.art`

若本文档与代码出现差异，应先核对 `src/` 中的现有实现和 `AGENTS.md` 中的最新决策，再同步修正文档。

## 1. 全局视觉基础

### 1.1 色彩

| 用途 | 色值/规则 |
| --- | --- |
| 页面主背景 | `#000000` |
| 主文字 | `#f4f4f2` / `#f4f4f5` |
| 次级文字 | `#858585` |
| 弱化文字 | `#575757`、`#696969` |
| 项目详情底色 | `#0c0c0c` |
| 项目详情遮罩 | `rgb(0 0 0 / 58%)` + `blur(8px)` |
| 细分隔线 | `0.5px solid rgb(255 255 255 / 5%)` |
| 移动端详情顶线 | `1px solid rgb(255 255 255 / 9%)` |

禁止使用白色或浅色页面底色。HTML、Body、React 根节点和 WebGL Canvas 在页面加载的第一帧都必须保持黑色。

### 1.2 字体

基础字体栈：

```css
"PingFang SC", "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif
```

使用场景：

- 常规界面文案：13px，行高约 18px。
- 辅助信息：12px。
- 大型英文品牌和摄影标题：`Geist` 优先，粗体、紧字距。
- 项目详情：`JetBrains Mono`、系统等宽字体和中文字体组合。
- 除大型品牌或标题外，不随屏幕任意放大界面字号。

### 1.3 边距与页面锚点

桌面端：

```css
--edge-x: clamp(18px, 1.3889vw, 28px);
--edge-y: clamp(16px, 2.2222vh, 28px);
```

移动端：

```css
--edge-x: 10px;
--edge-y: 24px;
```

左上品牌、右上导航、左右下角提示和计数应共享这些边缘锚点，避免各页面出现位置漂移。

### 1.4 背景网格

- 首页主要依靠纯黑画布，不添加显眼纹理。
- 预加载页、摄影页和部分内容区可使用极弱的四列/三行网格。
- 网格透明度控制在 2%–4%，只用于建立秩序感，不能成为主体。
- 移动端关于页和摄影详情页不显示背景网格。

### 1.5 层级

主要层级从低到高：

1. 黑色页面背景。
2. 首页 WebGL 海报画布。
3. 首页文案、项目索引和缩略图。
4. 项目详情覆盖层。
5. 关于页或摄影页。
6. 摄影详情大图层和全局导航。
7. 首次进入预加载层。

## 2. 全局导航与通用控件

### 2.1 顶部导航

固定在右上角，包含：

- `/ 项目`
- `/ 摄影`
- `/ 关于`

规则：

- 13px 字号，项目间距 20px；移动端间距 16px。
- 默认 `#858585`，当前页面和悬停状态为 `#f4f4f2`。
- 首次进入首页时随页面淡入；第二次及以后返回首页时直接显示，不重复淡入。
- 页面切换不得出现两组导航重叠或粘连的触摸悬停状态。

### 2.2 斜杠交互

- 悬停或键盘聚焦时，`/` 在原位水平翻转为 `\`。
- 斜杠翻转时长：160ms。
- 文字延迟 20ms 后向右移动 5px，时长 180ms。
- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)`。
- 斜杠和文字必须保持同一基线，不能上下抖动或被裁切。
- 移动端不播放粘性 Hover 动画。

### 5.3 焦点与可访问状态

- 键盘焦点使用 1px 浅色轮廓和 2px 外偏移。
- 当前导航通过 `aria-current="page"` 表达。
- 按钮和链接必须保留准确的中文 `aria-label`。
- `prefers-reduced-motion: reduce` 下，大型进入动效和过渡应缩短到接近即时完成。

## 6. 首次进入与预加载

首次进入首页时：

1. 黑色预加载页显示大型双行品牌文字。
2. 品牌从画面左下区域进入，并缩放移动到正式品牌位置。
3. 关键首页图片完成真实加载和解码后，黑色覆盖层向右移出。
4. 首页文案与首轮 WebGL 海报在同一节拍中出现。

关键参数：

- 品牌文字进入：约 1100ms。
- 品牌位置/缩放过渡：约 700ms。
- 覆盖层离场：约 900ms。
- 首页界面淡入：1350ms ease。

直接访问 `/Photo`、`/Photo/N` 或 `/About` 时，不应闪现首页内容或强制播放首页预加载。

## 7. 项目首页

### 7.1 内容结构

桌面端包括：

- 左上：品牌 `辜锟泓`。
- 右上：全局导航。
- 右上内容区：地点、时间、个人介绍和联系方式。
- 左侧中部：8 个项目索引。
- 中央：WebGL 3D 海报轨道。
- 海报左右：项目类型、项目范围和查看操作。
- 右侧中部：当前项目的前 5 张缩略图。
- 左下：`/ 上下滑动`。

首页联系文案固定为：

```text
zhi_9650 / 357512393@qq.com
```

### 7.2 项目顺序

1. 2026 Portfolio
2. 知识付费直播项目
3. PC直播助手
4. AI设计工作流
5. AI应用集合
6. AI官网设计
7. 留学酱
8. 其他设计

`2026 Portfolio` 是首页入口，进入详情时跳转到“知识付费直播项目”。项目详情导航因此保留 7 个实际案例。

### 7.3 项目索引

- 固定在左侧并垂直居中。
- 每行高度与行高均为 22px。
- 默认 `#575757`，当前项目为浅色并增加字重。
- 悬停或聚焦时只移动文字 5px，按钮点击区域本身不能移动。

### 7.4 3D 海报

- 海报为 16:9，保持原始比例，不拉伸。
- 沿全屏竖向 3D 螺旋运动，包含透视深度、倾斜、亮度衰减和软性弯曲。
- 鼠标滚轮、拖拽和移动端触摸均可切换项目。
- 输入停止后必须吸附到最近的项目，不能停在项目之间。
- 当前海报始终位于正确的视觉前景，使用深度测试而不是 DOM 顺序控制遮挡。
- 桌面精细指针下，仅当前海报具有最大约 16° 的 Tilt 响应和 1.2 倍放大；移动端禁用。
- 当前海报点击打开详情，相邻海报点击仅切换选择。

### 7.5 桌面与移动差异

- 桌面主布局最低宽度为 1280px，以保持参考构图。
- 海报可见宽度在 1280px 时约 240px，在 1920px 时约 360px。
- 移动端隐藏介绍、项目类型、项目范围和右侧缩略图。
- 移动端保留品牌、导航、项目索引、项目编号和 3D 海报。
- 移动端左下提示改为不可点击的“滑动浏览”。

## 8. 项目详情覆盖层

项目详情不是独立白页，而是覆盖在仍然挂载的首页上。

### 8.1 桌面结构

- 全屏半透明黑色遮罩：58% 黑 + 8px 模糊。
- 左侧项目列：200px。
- 中间文案列：目标 460–540px，最小 350px。
- 右侧媒体列：占据剩余宽度并独立纵向滚动。
- 项目行：连续 60px 高，13px 标签。
- 当前项目使用标签后方 6px 白色方块标记。
- 正文包含项目标题、年份、描述和关键成果。
- 媒体图片之间保持 12px 间距和 4px 圆角。

### 8.2 视觉材质

- 左侧面板使用 `color-mix(in oklch, #0c0c0c 96%, transparent)`。
- 面板使用 `backdrop-filter: blur(10px)`。
- 媒体列使用约 70% 深色半透明底和 12px 模糊。
- 分隔线统一为 0.5px、5% 白色透明度。
- 不添加额外边框、图标、头像或“访问网站”按钮。

### 8.3 项目切换动效

- 文案从左侧小幅偏移、模糊和低透明度进入，约 360ms。
- 首张媒体从较大位移和缩放状态快速归位，约 320ms。
- 后续媒体以小幅缩放和透明度变化进入。
- 图片完成预加载和解码后再显示详情层，避免白帧或空图。
- 当前、前一个和后一个项目的媒体应提前加载。

### 8.4 移动端/窄屏结构

项目详情在不超过 1100px 时切换为底部抽屉：

- 高度和最大高度：85dvh。
- 顶部圆角：24px。
- 顶部细线：1px、9% 白色。
- 顶部中央把手：40 × 5px。
- 媒体与正文使用同一纵向内容面。
- 只有正文内容真实溢出时才允许滚动。
- 底部上一项/下一项导航固定在抽屉内部。

## 9. 摄影首页

### 9.1 结构

- 黑色背景和极弱网格。
- 左上大型摄影标题与辅助文案。
- 中央 64 张正方形封面的 3D 轨道。
- 右上全局导航。
- 左下 `/ 返回项目`。
- 右下“滚动浏览”或移动端“滑动浏览”。

### 9.2 3D 浏览

- 桌面封面尺寸约 300 × 300px，中等宽度为 250 × 250px，移动端为 200 × 200px。
- 舞台透视为 2000px；移动端为 1500px。
- 卡片使用 Z 轴深度和 Y 轴旋转形成纵深轨道。
- 悬停卡片向上移动 14px。
- 页面重新进入时保留 3D 位置与已解码图片，不重播轨道入场。
- 文字淡入可以在每次进入时重播，但不能重置图片轨道。

移动端轨道整体定位：

```css
left: calc(50% - 50px);
top: calc(50% + 50px);
```

## 10. 摄影详情

### 10.1 桌面布局

- 左侧为 64 张自然比例缩略图组成的有限轨道。
- 缩略图宽度 80px、间距 16px，容器宽度 176px。
- 缩略图围绕屏幕中心形成向右弯曲的曲线。
- 中央高清图保持自然比例，最大宽度 `min(100vw - 352px, 1180px)`。
- 高清图最大高度为视口高度减 128px。
- 底部中央为 `/ 返回项目`，点击直接回到 `/`。
- 右下显示 `当前序号/64`。

### 10.2 移动端布局

- 左侧缩略图宽度 56px，轨道区域宽度 96px。
- 高清图最大宽度为 `100vw - 108px`。
- 高清图最大高度为 `100vh - 112px`。
- 大图和计数必须完整留在视口内。

### 10.3 滚动与切换

- 缩略图支持滚轮、鼠标拖拽和触摸拖拽。
- 停止滚动 140ms 后吸附到距离中心最近的缩略图。
- 桌面常规滚动插值 0.03，移动端 0.08。
- 开始吸附后，桌面插值提高到 0.12，移动端提高到 0.18。
- 曲线位置插值保持 0.08。
- 切换大图时不重新创建缩略图动画状态，不得出现抖动。
- 已加载高清图保持挂载；快速上下浏览时不能退回模糊图。

## 12. 动效系统

| 场景 | 时长 | 缓动/规则 |
| --- | --- | --- |
| 首页界面淡入 | 1350ms | `ease` |
| About 文字遮罩揭示 | 760ms | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 摄影标题揭示 | 1100ms | 同上，第二行延迟 150ms |
| 斜杠翻转 | 160ms | 同上 |
| 控件文字右移 | 180ms | 同上，延迟 20ms |
| 项目索引文字移动 | 180ms | 同上 |
| 摄影封面 Hover | 280ms | 同上 |
| 项目详情文案切换 | 360ms | 同上 |
| 项目详情首图切换 | 320ms | 同上 |

动效原则：

- 位移应短、明确，不使用无意义的循环动画。
- 页面返回时优先复用状态，不重新加载或重建重型画布。
- 动效不能改变最终布局，也不能造成斜杠、文字或图片抖动。
- Reduced Motion 模式必须保留状态变化，但将动画压缩为近乎即时完成。

## 13. 图片资源与加载策略

### 13.1 首页与项目

- 首页封面：`public/assets/home-covers/`。
- 项目详情：`public/assets/projects/`。
- 项目缩略图：`public/assets/project-thumbnails/`。
- 项目图片使用 WebP，最长边不超过 2048px。
- 首页右侧每个项目只展示前 5 张缩略图。

### 13.2 摄影三档资源

| 层级 | 目录 | 用途 |
| --- | --- | --- |
| 封面 | `assets/photography-covers/1.webp`–`64.webp` | 摄影首页 3D 卡片 |
| LQIP/缩略图 | `assets/photography-thumbnails/1.webp`–`64.webp` | 左侧轨道与模糊占位 |
| 高清展示图 | `assets/photography/1.webp`–`64.webp` | 摄影详情大图 |

资源预算：

- 高清展示图：每张 70–90KB。
- LQIP：每张 5–10KB。
- 删除 EXIF、GPS 和相机信息。
- 原始 JPG 仅保存在本地备份目录，不进入 `public/` 或部署包。

加载顺序：

1. 摄影封面和轻量缩略图优先加载。
2. 进入详情后，当前大图立即获得真实 `src`。
3. 当前图前后各 2 张以高优先级预取。
4. 64 张封面加载完成后，后台继续加载全部高清图。
5. 已加载/已解码高清图在本次摄影会话中持续挂载。

摄影高清图和缩略图使用共享版本参数 `PHOTOGRAPHY_ASSET_VERSION`。替换任何固定文件名图片时必须同步提升版本值，避免浏览器继续显示旧图。

## 14. 响应式断点

| 范围 | 主要行为 |
| --- | --- |
| `≥1280px` | 完整桌面首页构图和桌面项目详情 |
| `810–1279px` | 首页保持桌面逻辑，摄影卡片适度缩小 |
| `≤1100px` | 项目详情切换为底部抽屉 |
| `≤809px` | 首页、摄影和关于切换为移动布局 |
| 高度 `≤760px` | 首页中部文案轻微下移以保持视觉平衡 |

移动端不是桌面端的等比缩小。所有移动规则应独立维护，避免桌面参数直接覆盖移动构图。

## 15. 性能与缓存

- 首页 WebGL 和摄影页首次挂载后应保持组件与已解码图片，离开页面时只暂停动画和事件。
- 进入其他页面后返回首页，不重新创建 WebGL 纹理或重复下载首页图片。
- 静态摄影资源在 Vercel 使用一年不可变缓存；内容变化通过版本参数生成新 URL。
- `index.html` 不使用长期不可变缓存。
- 当前站点是纯静态 Vite 页面，不需要 Functions Region。
- 暂不使用 Vercel 动态图片优化；优先使用预先压缩的静态 WebP。
- Vercel Speed Insights 在 React 根节点挂载一次，用于观察 LCP、INP 和 CLS。

## 16. 无障碍与输入适配

- 所有主要页面区域具有明确的 `aria-label`。
- 当前页面、当前缩略图和活动项目具有可识别状态。
- 图片 Alt 文本描述项目名或摄影作品序号；纯装饰缩略图可使用空 Alt。
- 所有鼠标交互必须有键盘等价入口。
- 触摸设备不依赖 Hover 才能完成关键操作。
- 页面级滚动区域通过 `overscroll-behavior` 隔离，避免滚动穿透。
- 大图与项目详情加载过程中不得出现白色背景闪烁。
