# Part A：视觉规范模板

## A1. 视觉方向

### A1.1 本站固定原则

- 纯黑画布，第一帧不能出现白色背景。
- 作品图片和摄影图片是视觉中心，界面保持克制。
- 使用细字号、低饱和辅助文字和极弱分隔线。
- 通过空间、层级、透视和模糊建立沉浸感。
- 不新增与现有体系重复的颜色、字号或阴影。
