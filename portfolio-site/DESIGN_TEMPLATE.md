# KUN HONG Portfolio 设计模板规范

> 模板版本：1.0  
> 最后更新：2026-08-16  
> 适用范围：新增页面、项目案例、摄影内容、通用组件及响应式改版

## 1. 使用方法

本文件是一份可复用的设计模板。新增任何页面或模块时，应先复制对应章节中的模板，再填写内容，不要从空白状态重新定义视觉规则。

使用顺序：

1. 选择页面类型：项目首页、项目详情、摄影首页、摄影详情、关于页或通用内容页。
2. 使用本文档中的全局 Token、栅格和组件，不创建同义但数值不同的新样式。
3. 同时完成桌面端、移动端、键盘、触摸和 Reduced Motion 状态。
4. 使用文末验收表检查视觉、交互、图片、性能和路由。
5. 若新需求必须偏离模板，应先记录原因，再同步更新 `DESIGN.md` 与 `AGENTS.md`。

## 2. 核心设计原则

所有新增设计必须满足以下五点：

- **黑色画布**：背景始终以纯黑为基础，不引入大面积浅色页面。
- **内容主导**：图片、作品和经历是主角，界面只承担导航和信息组织。
- **低噪声**：细字号、低饱和辅助色、少量分隔线，不添加无意义装饰。
- **空间连续**：页面切换保留已加载内容和空间关系，避免突兀重置。
- **精确反馈**：Hover、Focus、拖拽、吸附、切换和加载状态都有明确反馈。

## 3. 全局设计 Token

### 3.1 色彩 Token

```css
:root {
  --color-bg: #000000;
  --color-surface: #0c0c0c;
  --color-text-primary: #f4f4f2;
  --color-text-strong: #ffffff;
  --color-text-secondary: #858585;
  --color-text-muted: #696969;
  --color-text-disabled: #575757;
  --color-line: rgb(255 255 255 / 5%);
  --color-line-mobile: rgb(255 255 255 / 9%);
  --color-backdrop: rgb(0 0 0 / 58%);
}
```

使用规则：

| 场景 | Token |
| --- | --- |
| 页面背景 | `--color-bg` |
| 当前项、正文、主要按钮 | `--color-text-primary` |
| Hover 强调 | `--color-text-strong` |
| 导航默认、年份、辅助信息 | `--color-text-secondary` |
| 时间、说明标签 | `--color-text-muted` |
| 未选项目 | `--color-text-disabled` |
| 桌面分隔线 | `--color-line` |
| 移动端抽屉顶线 | `--color-line-mobile` |

禁止：

- 为单个页面创建新的近似黑色或近似白色。
- 使用高饱和品牌色作为大面积背景。
- 使用阴影代替已确认的细线与模糊层级。

### 3.2 字体 Token

```css
:root {
  --font-ui: "PingFang SC", "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif;
  --font-display: "Geist", "Helvetica Neue", Arial, sans-serif;
  --font-mono: "JetBrains Mono", "SFMono-Regular", Consolas, "Liberation Mono", "PingFang SC", monospace;
  --text-body: 13px;
  --text-caption: 12px;
  --leading-body: 18.2px;
}
```

字号层级：

| 名称 | 桌面 | 移动 | 用途 |
| --- | ---: | ---: | --- |
| Display XL | `clamp(118px, 12.3vw, 218px)` | `clamp(84px, 23vw, 180px)` | 大型品牌文字 |
| Display L | `clamp(54px, 7vw, 112px)` | `clamp(40px, 13vw, 64px)` | 摄影标题 |
| Heading | 16px | 16px | 项目标题 |
| UI | 13px | 13px | 导航、索引、正文、计数 |
| Caption | 12px | 12px | 标签、经历辅助信息 |

规则：

- 常规界面默认使用 13px，不为了“更现代”随意增大。
- 大标题只使用展示字体，正文不使用超粗字重。
- 项目详情使用等宽字体体系，其余页面使用 UI 字体体系。
- 中文与英文混排保持自然字距，不对中文使用大范围大写转换。

### 3.3 间距 Token

```css
:root {
  --edge-x: clamp(18px, 1.3889vw, 28px);
  --edge-y: clamp(16px, 2.2222vh, 28px);
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
}

@media (max-width: 809px) {
  :root {
    --edge-x: 10px;
    --edge-y: 24px;
  }
}
```

优先从 4、8、12、16、20、24、32px 中选择间距。只有为了匹配现有固定构图时，才允许使用其他数值。

## 4. 页面骨架模板

### 4.1 通用页面骨架

每个完整页面按以下区域组织：

```text
Page
├── Header
│   ├── Brand（需要时）
│   └── Global Navigation
├── Primary Content
│   ├── Page Heading / Index
│   ├── Primary Media or Experience
│   └── Supporting Metadata
└── Edge Controls
    ├── Back / Scroll Hint
    └── Count / Status
```

要求：

- Header 与 Edge Controls 使用统一页面边距 Token。
- 页面主体不能遮挡右上导航。
- 页面离开时应移除无效事件监听，但可保留重型图片和画布状态。
- 直接打开非首页路由时，不显示首页闪屏或底层内容。

### 4.2 顶部导航模板

```text
/ 项目    / 摄影    / 关于
```

状态：

| 状态 | 文字颜色 | 行为 |
| --- | --- | --- |
| Default | `#858585` | 无位移 |
| Hover/Focus | `#f4f4f2` | 斜杠翻转、文字右移 5px |
| Current | `#f4f4f2` | 保持高亮 |
| Mobile Hover | 不变化 | 禁止触摸粘性 Hover |

模板约束：

- 桌面间距 20px，移动端 16px。
- 固定在 `top: var(--edge-y); right: var(--edge-x)`。
- 不新增汉堡菜单；当前三个入口在移动端仍直接展示。

### 4.3 边缘控件模板

允许的文字结构：

```text
/ 返回项目
/ 点击查看
/ 上下滑动
滑动浏览
当前序号/总数
```

规则：

- 可点击控件使用斜杠 Hover 模式。
- 纯提示文案不伪装成按钮。
- 桌面底部位置使用 `var(--edge-y)`；移动端统一 `bottom: 14px`。
- 摄影详情中的“返回项目”置于底部中央，其余返回控件通常位于左下。

桌面布局槽位：

固定规则：

- 左侧项目索引垂直居中，每行 22px。
- 中央媒体使用 16:9，不拉伸。
- 右侧缩略图最多 5 张，60 × 34px，间距 8px。
- 介绍区位于 `top: 16.5%; left: 70.6%`。
- 项目类型、范围和编号围绕当前海报构图，不覆盖海报。


## 6. 组件模板

### 6.1 斜杠标签

结构：

```jsx
<SlashHoverLabel label="返回项目" />
```

动效：

```css
/* slash */
transition: transform 160ms cubic-bezier(0.22, 1, 0.36, 1);

/* text */
transition: transform 180ms cubic-bezier(0.22, 1, 0.36, 1);
transition-delay: 20ms;
```

禁止：

- 用两个重叠字符模拟翻转。
- 改变斜杠宽度导致文字跳动。
- 在移动触摸端保留 Hover 位移。

### 6.2 列表项

```text
Default → Muted
Hover/Focus → 文字右移 5–8px + 颜色变亮
Active → Primary + 可选状态标记
```

点击热区必须固定，只有内部文字发生位移。

### 6.3 图片组件

每张内容图片至少提供：

- 明确的 `width` 和 `height` 或稳定的宽高比。
- 与内容匹配的 Alt；装饰图使用空 Alt。
- `decoding="async"`。
- 首屏关键图使用 `fetchPriority="high"`。
- 非关键图片根据页面策略使用延迟加载或后台预取。
- 黑色或深灰占位背景，禁止白色加载底。

### 6.4 计数器

格式：

```text
01
1/64
```

- 首页项目编号使用两位数。
- 摄影详情使用“当前/总数”。
- 固定在边缘，不随图片尺寸移动。

## 7. 动效模板

### 7.1 标准缓动

```css
--ease-out-smooth: cubic-bezier(0.22, 1, 0.36, 1);
--ease-cover: cubic-bezier(0.77, 0, 0.175, 1);
```

### 7.2 标准时长

| 类型 | 时长 |
| --- | ---: |
| 微交互 | 160–180ms |
| 图片轻过渡 | 220–280ms |
| 项目内容切换 | 320–420ms |
| 文字遮罩揭示 | 760–1100ms |
| 页面整体淡入 | 1350ms |

### 7.3 页面进入模板

```text
初始状态：内容已占据最终布局，仅透明度或裁切隐藏
进入状态：透明度/裁切恢复
结束状态：移除 will-change，保留最终位置
```

禁止使用会造成布局变化的 `top`、`left` 动画。优先使用 `transform`、`opacity` 和 `clip-path`。

### 7.4 Reduced Motion

```css
@media (prefers-reduced-motion: reduce) {
  .animated-element {
    animation-duration: 1ms;
    transition-duration: 1ms;
    transition-delay: 0ms;
  }
}
```

状态切换和导航仍必须有效，不能因为减少动画而隐藏内容。

## 8. 响应式模板

### 8.1 断点

```css
/* Mobile */
@media (max-width: 809.98px) {}

/* Project detail drawer */
@media (max-width: 1100px) {}

/* Medium photography */
@media (min-width: 810px) and (max-width: 1199.98px) {}

/* Desktop */
@media (min-width: 1280px) {}
```

### 8.2 响应式决策顺序

新增模块必须按以下顺序决定：

1. 哪些内容是移动端必须保留的核心信息？
2. 哪些桌面辅助元素应该隐藏，而不是缩小？
3. 交互应从 Hover/滚轮如何转换为触摸/拖拽？
4. 固定元素是否会遮挡安全区域和浏览器工具栏？
5. 内容溢出时由哪一个容器负责滚动？

### 8.3 移动端禁用项

- 不显示桌面介绍区、项目范围和右侧缩略图轨道。
- 不使用桌面 Tilt Hover。
- 不使用触摸后持续存在的 Hover 颜色和位移。
- 不把桌面项目详情的三栏布局压缩到小屏。
- 不允许多个嵌套纵向滚动容器相互竞争。

## 9. 图片模板规范

### 9.1 文件命名

```text
[目录]/1.webp
[目录]/2.webp
[目录]/3.webp
```

固定序列优先使用连续数字，避免中文、空格和时间戳进入线上 URL。

### 9.2 输出标准

| 类型 | 格式 | 尺寸/预算 |
| --- | --- | --- |
| 首页封面 | WebP | 16:9，适配最高显示尺寸 |
| 项目详情 | WebP | 最长边 ≤2048px |
| 摄影封面 | WebP | 720 × 720px |
| 摄影 LQIP | WebP | 5–10KB，自然比例 |
| 摄影高清图 | WebP | 70–90KB，自然比例 |

处理要求：

- 删除 EXIF、GPS 和相机信息。
- 保留本地原图备份，但不部署。
- 同一张图片只进行一次有损编码，避免重复压缩。
- 替换固定文件名资源后提升资源版本号。

## 10. 内容模板规范

### 10.1 项目摘要

```text
[项目背景/服务对象] + [设计范围] + [解决的关键问题]
```

长度建议：40–90 个中文字符。

### 10.2 项目成果

每个项目保留 3 条，句式优先使用：

```text
[动作] + [对象/流程] + [产生的改进]
```

示例：

```text
重构直播前、中、后的任务流程与信息架构，降低高频操作成本。
```

### 10.3 界面文案

- 操作使用动词：查看、返回、滑动、切换。
- 不使用“点击这里”“更多”等含义不明确的词。
- 中文标点和中英文空格保持统一。
- 品牌名、项目名、联系方式必须与内容源一致。

## 11. 路由与状态模板

新增公开页面时必须定义：

```text
页面名称：
公开路径：
直接刷新是否恢复：是
浏览器返回行为：
旧路径兼容方式：
Vercel Rewrite 是否覆盖：是
```

规则：

- 公开页面使用干净 History API 路径。
- 所有静态资源必须从域名根路径 `/assets/...` 解析。
- 项目详情仍在首页覆盖层打开，除非明确批准改变信息架构。
- `/Photo/N` 必须在刷新后恢复对应摄影作品。
- 任何返回项目操作都应回到 `/`。

## 12. 可访问性模板

新增组件至少检查：

- [ ] 使用正确的 `button`、`a`、`nav`、`section`、`figure` 语义。
- [ ] 交互元素具有明确中文 `aria-label`。
- [ ] 当前页面使用 `aria-current="page"`。
- [ ] 当前摄影缩略图使用 `aria-current="true"`。
- [ ] 键盘可以完成鼠标能够完成的核心操作。

- HTML 不设置一年不可变缓存。
- 不在 Vercel CDN 外再叠加一层 ESA/CDN。

## 17. 禁止偏离项

除非获得明确的新设计确认，不得：

- 改变纯黑整体背景。
- 修改首页、项目或摄影的既定顺序。
- 将项目详情改成脱离首页的普通独立页面。
- 移除项目详情后的模糊首页层。
- 将全局导航改成汉堡菜单。
- 在移动端直接压缩桌面三栏详情。
- 用动画隐藏加载延迟，而不解决资源加载。
- 让已加载摄影大图重新显示模糊占位。
- 为同一功能创建第二套颜色、字号或动效参数。
- 在 React 页面中实现域名 301 跳转。
